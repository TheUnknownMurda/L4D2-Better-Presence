## Decisions taken with Sam (2026-10-14/15)

- Source: the engine's network console (`-netconport` + `-netconpassword` + `-g15`), no mod (VAC).
- Card in English. Line 1 = campaign · chapter · difficulty (no chapter number n/N). Line 2 rotates health &
  weapon / team (online only, never "Solo with N bots") / Survival best; no specials line by default; "limping"
  only when revived under 30 HP.
- Weapon name only (no ammo, no "reloading"; `show_ammo` stays as an option).
- Survival has its own card; best = max(times measured by the companion in `survival_records.json`,
  records typed by the user in config `survival_records`, the Gold Miners GM Demo Archive when
  `gm_demo_archive` is on — on for Sam; the game's own are not readable).
- Realism dropped: undetectable in solo without an add-on, and Sam does not want an add-on.
- Images: cover and the 8 survivor portraits are Sam's links (guns.lol), defaults of `cover_image` /
  `character_images`. config.json only holds the keys a user changes (defaults stay live).
- Published like the rest of the series: public GitHub repo `TheUnknownMurda/L4D2-Better-Presence`, release zip
  linked from the README. Personal details (Steam account id, Discord account names, local IPs, Windows user name)
  were scrubbed from files and history before the first push — keep it that way.

## Architecture

```
game console (TCP 127.0.0.1:27015) ─► netcon.py ─► parser.py (lines → events) ─► state.py (Tracker, GameState)
                                                                                      │
Steam localconfig.vdf ─► steam.py (port, password)            presence.py (state → card, pure) ◄─ config.py
process list / idle ─► system.py                                     │
                                         app.py (loop, Sender: 5 s important / 15 s minor) ─► discord_ipc.py
```

- `l4d2_rpc/data/` — `game_data.json` (names from the game files) and `images.json` (wiki/Steam links), both
  generated by `tools/build_data.py`.
- `l4d2_rpc/simulate.py` — fake game through every situation, in the real line formats (`--simulate`, tests).
- `__main__.py` — CLI: run, `--dry-run`, `--simulate`, `--dump`, `-v`, `install`, `uninstall`, `doctor`, `setup`,
  `startup on|off`. `install.py` — Install.bat / Uninstall.bat steps (PID file `%LOCALAPPDATA%\L4D2RPC\companion.pid`).
- `records.py` — Survival best times.
- `tools/` — `vpk.py` (VPK reader), `vtf.py` (texture → PNG), `netcon_probe.py`, `analyze_netcon.py`,
  `build_data.py`, `make_fixtures.py`, `extract_portraits.py`.
- `tests/` — fixtures cut from real recordings (anonymised), fake Discord (pipe), fake netcon (TCP).
- Launchers (all a user needs): `Install.bat`, `Uninstall.bat`, `Doctor.bat`, `L4D2RPC.bat` (console).

Reused code (MIT, same author): Discord IPC client and fake Discord from `../FL Studio Better Presence`, process
helpers from `../Dead by Daylight Better Presence/dbd_rpc/game.py`, pacing/rotation ideas from
`../Sons of the Forest Better Presence/sotf_rpc/`.

## Technical rules

See `../_Prompt Better Presence.md` (`<regles_discord>`, `<sources_de_donnees>`, `<pieges_connus>`). Reminders:
- Only read-only console commands (`status`, cvar reads, `g15_dumpplayer`). Never write to the game, Steam or
  saves. Never show IDs, IPs, other players' names or positions.
- Every card text goes through `presence.truncate()`. Timestamps in seconds.
- Never write `\uXXXX` escapes or raw control characters in sources with the editing tools (use `chr()`).
- PowerShell from code: one line for `-Command`, no double quotes, never `-EncodedCommand`.
